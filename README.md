# Perspectives on Doctoral Quantitative Methods Training in Times of AI and Other Threats to Rationality

Slides for a talk given at **Statistical Modeling in Psychology (SMiP)** — Mannheim, Germany, September 18, 2026.

**Author:** Jonathan Templin · Clemson University, College of Education

## ▶️ View the talk

**<https://jonathantemplin.github.io/smip-farewell-2026/>**

The presentation is a self-contained [reveal.js](https://revealjs.com/) slide deck (all images and styles embedded), so the link above is all you need — no installation required.

## Reproducing the slides

The deck is built with [Quarto](https://quarto.org/).

```bash
quarto render "SMiP 2026 Presentation.qmd"
```

That regenerates `SMiP 2026 Presentation.html`; the published site (`index.html`) is a copy of that rendered file.
